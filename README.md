# car_insurance_dataset
Insurance claims and premium analysis using Python, MySQL, and Power BI

## Project Overview
This project simulates an insurance portfolio dataset and analyzes claims, premiums, and profitability.

## Tools Used
- Python (Dataset generation)
- MySQL (Data analysis)
- Power BI (Visualization dashboard)

## Key Insights
- Total premium collected in 2024
- Monthly claim trends
- Loss ratio analysis
- Profitability by policy tenure
